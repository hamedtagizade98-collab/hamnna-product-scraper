# Hamnna SEO Links Manager

افزونه وردپرس/ووکامرس برای مدیریت سئوی محصولات همنا.

## امکانات

- دو تب جدید در صفحه محصول ووکامرس:
  - **لینک داخلی**
  - **لینک خارجی**
- امکان ثبت چند URL، هر URL در یک خط.
- خروجی CSV از تمام محصولات با ساختار مناسب برای پردازش دسته‌ای.
- ستون‌های خروجی:
  - اسم محصول
  - توضیحات محصول
  - جدول ویژگی (توضیحات کوتاه)
  - سئو عنوان
  - متا
  - آلت عکس
  - برچسب
  - URL
  - کلمه کلیدی
  - لینک داخلی
  - لینک خارجی
- پشتیبانی از متادیتای Yoast و Rank Math برای عنوان، متا و کلمه کلیدی.
- ورود CSV و به‌روزرسانی لینک‌های داخلی/خارجی بر اساس URL محصول.
- نمایش وضعیت لینک داخلی و خارجی در لیست محصولات.

## نصب

1. پوشه `hamnna-seo-links-manager` را ZIP کنید.
2. در وردپرس از **افزونه‌ها > افزودن افزونه > بارگذاری افزونه** فایل ZIP را نصب کنید.
3. افزونه را فعال کنید.
4. در صفحه هر محصول، دو تب جدید را در بخش اطلاعات محصول می‌بینید.
5. از مسیر **ووکامرس > Hamnna SEO Links** می‌توانید CSV همه محصولات را دریافت یا CSV لینک‌ها را وارد کنید.

## نکته مهم

افزونه URLهای خارجی را حدس نمی‌زند؛ لینک‌های واقعی باید از CSV یا پنل محصول وارد شوند تا لینک اشتباه تولید نشود.
