# Hamnna Product Scraper for WooCommerce

افزونه اختصاصی برای وارد کردن محصولات موجود از `hamnna.ir` به WooCommerce.

## امکانات
- اجرای خودکار اسکرپر هر ۳ ساعت
- اجرای دستی از پیشخوان
- جلوگیری از وارد کردن دوباره محصول با شناسه محصول منبع
- رد کردن محصولاتی که ناموجود تشخیص داده شوند
- وارد کردن عنوان، توضیحات، قیمت و تصویر شاخص
- ذخیره URL و شناسه محصول منبع در متادیتای محصول
- قفل اجرای همزمان
- گزارش تعداد بررسی، جدید، تکراری، ناموجود و خطا
- تنظیم تعداد محصول در هر اجرا
- تبدیل تصاویر JPG/PNG به WebP
- هدف حداکثر حجم ۲۰۰KB برای تصویر اصلی و سایزهای تولیدشده
- کاهش مرحله‌ای کیفیت WebP تا رسیدن به سقف ۲۰۰KB
- پردازش خودکار ۲۵ تصویر در هر اجرای زمان‌بندی‌شده
- پردازش دستی ۲۵ تصویر از پنل مدیریت
- جلوگیری از پردازش دوباره تصاویر بهینه‌شده

## بهینه‌سازی تصاویر
از منوی «اسکرپر همنا → بهینه‌سازی تصاویر» می‌توان تصاویر قبلی را به‌صورت دسته‌ای بهینه کرد. تصاویر جدید نیز هنگام تولید متادیتای رسانه، بهینه می‌شوند.

توجه: رسیدن به حداکثر ۲۰۰KB یک هدف فنی است؛ اگر یک تصویر با حداقل کیفیت قابل‌قبول همچنان بزرگ‌تر از ۲۰۰KB باشد، آخرین خروجی ممکن نگه داشته می‌شود تا کیفیت بیش از حد تخریب نشود.

## نصب
1. پوشه `hamnna-product-scraper` را داخل `wp-content/plugins/` قرار دهید.
2. فایل `hamnna-product-scraper.php` باید در ریشه همین پوشه باشد.
3. WooCommerce را فعال کنید.
4. افزونه را از Plugins فعال کنید.
5. از منوی «اسکرپر همنا» تنظیمات را بررسی کنید.
6. از زیرمنوی «بهینه‌سازی تصاویر» برای پردازش تصاویر قبلی استفاده کنید.

## نکته مهم
ساختار HTML سایت منبع باید با selectorهای نسخه نهایی تطبیق داده شود. نسخه فعلی از کشف لینک‌های `/product/` و استخراج عمومی HTML استفاده می‌کند؛ برای وارد کردن همه فیلدهای اختصاصی، دسته‌بندی، برند، گالری و تشخیص ۱۰۰٪ دقیق موجودی باید یک نمونه HTML واقعی از صفحه منبع در محیط قابل دسترسی بررسی شود.
